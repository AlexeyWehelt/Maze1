# Лабиринт со стикера

3D-лабиринт, построенный по рисунку на стикере: семь земель, динозавры, общий мир для нескольких игроков.

Играть: https://alexeywehelt.github.io/Maze1/

## Сетевая игра

Общий мир работает через Firebase Realtime Database. Настройки проекта лежат в `firebase-config.js`, правила базы — в `firebase-rules.json`. Пока в `firebase-config.js` стоит `null`, игра одиночная.

Для проверки без сервера откройте игру с `#local` в конце адреса в двух вкладках одного браузера.
